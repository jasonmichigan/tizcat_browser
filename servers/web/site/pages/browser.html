The browser

A complete browser, built for speed

TizCat is a complete, standalone browser. Google sign-in works, extensions work, and everything you expect from a modern browser is there, with a few things of its own.

Everything you expect

Nothing missing

  • Extensions and the Chrome Web Store
  • A password manager, encrypted for your Windows account
  • Video in full screen, tabs that drag between windows, printing and PDF reading
  • Security fixes with every TizCat update
  • Yuzal, TizCat's AI agent, built into the side panel
Switching made easy

It brings your data with you

TizCat finds the other browsers on your computer, one entry per profile, and brings bookmarks, history, saved passwords, the search engines you added and form entries.

One honest limit

Chrome and Edge now lock saved passwords to themselves with app-bound encryption that no other program can read. Export those from that browser's password manager as a file and import the file into TizCat. Passwords from Brave, Opera and the others import directly.

A Profile page, as Brave has

Settings opens on Profile: your TizCat account, your profile's name and icon, import from other browsers, the default browser and what opens on startup, in one card. A JibWallet page sits in the menu where Brave has Web3.

A New Tab page of its own

A full-screen picture, the time, a search box that uses your chosen search engine, shortcuts to the sites you visit most, and a small TizCat Rewards card. It is made only of files already on your computer.

The New Tab page and the address bar also carry a few sponsored shortcuts and suggestions, each labeled Sponsored, and partner bookmarks for shopping and travel sites. Details coming soon...

Speed

Compiled for speed

TizCat is built with profile-guided optimization: a profile of real browsing workloads records which code runs most, and the final build is laid out around it.

A further build step, ThinLTO, needs more memory to link than a laptop has free; it comes when TizCat is built on a larger machine.

Numbers, honestly

Speedometer 3, JetStream 2, MotionMark, startup time and memory will be measured against Chrome and Brave on the same computer and published, including any test TizCat loses.
